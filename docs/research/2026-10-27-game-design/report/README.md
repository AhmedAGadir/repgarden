# Report generator

`python3 gen.py` writes `../report.html` from `store-meta.json`, `../apps.json`, `front.py` (cover, goals, theme, screen types), `outcomes.py` (summary and the decision pages), `evidence.py` (the per-game pages; the condensed cells there are an editorial reading of `../findings.md`) and `evidence_fixed.py` (scale, the streak thread, method). `node pdf.mjs ../report.html ../report.pdf` prints it to A4 with Chrome; `python3 tomd.py ../report.html ../report.md` writes the Markdown twin; `BLUR=1 python3 gen.py` writes the version with names, icons and screenshots frosted, printed to `../report-blurred.pdf`. Delete `report.html` afterwards. `merge.py` rebuilds `../apps.json` from the three lanes' `apps.json` files (kept under `../evidence/`). Fonts come from the console repository's brand pack. Icons are committed; the screenshots in `shots/` (60 MB) are not, and `python3 fetch_images.py && python3 refetch.py` refetches both from the iTunes lookup API using the ids in `apps.py` (Grow a Garden's come from the Roblox thumbnail API; its URLs are in `store-meta.json`). `gen.py` needs `shots/` to rebuild the PDFs.
