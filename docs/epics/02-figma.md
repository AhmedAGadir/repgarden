# Epic 02 — Connect Figma and create the project overview

Outcome: a private, editable RepGarden design file that the learner has inspected.

## Phase 1 — Connect

- [ ] Read project instructions, progress and brief. Identify the learner’s agent and whether Figma is already connected.
- [ ] Consult the official setup guide for that agent: https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/
- [ ] Help install the official Figma plugin where supported. Explain any user actions. The learner completes sign-in and permission prompts in the provider UI; never request credentials in chat.
- [ ] Verify the available Figma tools, including native editing. Report missing capabilities, plan limits or access errors honestly. Do not buy an upgrade or make a file public.

Stop here until the learner asks to create the overview.

## Phase 2 — Create useful project material

- [ ] Use the connected tools to create a Figma Design file named RepGarden in the learner’s Drafts. If file creation requires a user action, guide that action and obtain the resulting file link; do not claim to have created it yourself.
- [ ] Add a simple editable frame named Project overview with the heading RepGarden and three labelled notes: Trainers — manage clients and assign workouts on the web; Clients — follow and log workouts on iOS and Android; Mascots — vegetable characters progress with training.
- [ ] Use simple neutral styling. Do not choose a final brand, generate artwork, build screens or start another epic. Return the file/frame link.
- [ ] Inspect the created content with the tools and report what exists, distinguishing tool evidence from the learner’s visual check.
- [ ] Ask the learner to open the link and confirm the content is correct and the text is editable.
