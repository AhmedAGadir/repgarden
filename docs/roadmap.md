# RepGarden build outline

Only epics 01 and 02 are ready to follow. This is a provisional sequence, not authorisation to build everything. Detailed epics will be added as the course is rehearsed.

1. Workspace and project context — docs/epics/01-workspace.md
2. Figma connection and project overview — docs/epics/02-figma.md
3. Branding — generate options and vegetable mascot styles, choose a direction and create a small brand pack.
4. User flows and wireframes — main trainer/client journeys and feedback.
5. Architecture and project scaffolding — select the stack and explain tradeoffs.
6. Accounts, trainer/client isolation and invitations.
7. Reviewed exercise library and AI content pipeline.
8. Workout assignment, logging and progress.
9. Bookings and session payments.
10. Mascot progression and mobile reminders.
11. Verification, operational tools, web deployment and support/privacy/deletion pages.
12. iOS and Android release — approval and any review-driven fixes.

The reference repository will contain our chosen branding and implementation. Learners generate their own branding during the relevant activity; finished assets are not required to begin. Do not silently download future instructions or overwrite learner work when a new starter release appears.
