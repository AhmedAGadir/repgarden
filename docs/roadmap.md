# RepGarden build outline

This is a provisional product outline, not a lesson sequence or permission to implement everything. Epics record actual work and evidence as we build.

1. Workspace and project context — docs/epics/01-workspace.md
2. Repository history and maintenance — docs/epics/02-git.md
3. Design workspace and prototypes — docs/epics/03-figma.md
4. Branding — generate options and vegetable mascot styles, choose a direction and create a small brand pack.
5. User flows and wireframes — main trainer/client journeys and feedback.
6. Architecture and project scaffolding — select the stack and explain tradeoffs.
7. Accounts, trainer/client isolation and invitations.
8. Reviewed exercise library and AI content pipeline.
9. Workout assignment, logging and progress.
10. Bookings and session payments.
11. Mascot progression and mobile reminders.
12. Verification, operational tools, web deployment and support/privacy/deletion pages.
13. iOS and Android release — approval and any review-driven fixes.

Branding and implementation belong in this repository as they are produced. Standalone guides may reuse demonstrated methods; there is no maintained learner starter or prescribed completion path.
